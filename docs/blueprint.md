# **App Name**: Orpheus AI

## Core Features:

- AI Chat Interaction: Enables users to submit text prompts and receive dynamic AI-generated responses from the Hack Club proxy, acting as an intelligent tool for interaction.
- Real-time Response Streaming: Displays AI responses character by character as they are generated, enhancing the user experience with a fluid, natural conversation flow.
- Chat Message History: Renders a persistent and scrollable feed of the ongoing conversation, preserving both user queries and AI replies.
- Fixed User Input Bar: Provides an always-visible text input field anchored at the bottom of the chat interface for continuous and convenient user interaction.
- Hack Club AI Proxy Backend Integration: Sets up the backend route handler to securely communicate with the Hack Club AI proxy using the specified base URL and authentication token, streaming AI data to the frontend.

## Style Guidelines:

- The primary interaction color is a rich, deep royal blue (#334DCC), providing a strong but cosmic accent against the dark theme.
- The background features a very dark, subtly blue-purple gray (#14161F) to establish the requested 'dark-themed, minimalist' aesthetic.
- A vibrant light blue/cyan (#5EBEED) serves as the accent color, offering clear visual contrast for alerts or highlights.
- The 'Orpheus AI' header text features a distinct gradient that transitions from a vivid Hack Club red (#F53D3D) to a deep cosmic blue (#0F388A).
- Body and headline font: 'Inter' (sans-serif) for its modern, objective, and highly legible appearance, suitable for a minimalist chat interface.
- Minimalist and sleek icons for actions like sending messages, with potential for subtle avatars to represent user and AI in the chat.
- A clean, minimalist layout with generous spacing, designed for focused chat interaction and resembling the Google Gemini interface, including an input bar fixed at the bottom.
- Subtle, smooth animations for chat messages appearing or updating, enhancing the real-time streaming experience without being distracting.
